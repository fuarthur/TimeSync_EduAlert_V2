# TimeSync EduAlert visual system

## Direction
Operate mode: a quiet, native Material 3 timetable, designed for a glance between classes. Replace the old saturated purple cards with a cool blue academic palette and clear time-first rows. System Roboto, native gestures and standard controls.

## Tokens
Primary light #2456A6 / dark #AEC6FF. On-primary white / #002E69. Surface light #F9FAFF / dark #111318. Surface variant light #E0E5F0 / dark #424752. Text light #191C22 / dark #E2E2E9. Error light #BA1A1A / dark #FFB4AB. Course colors are accents beside the course name, never the background behind all text.

## Type and space
Material headline/title/body/label roles. Titles 24sp, section headings 20sp, course names 18sp, body 16sp, supporting text 14sp. Outer gutter 20dp, groups 24dp apart, related items 8dp apart. 48dp minimum controls. Center content with a maximum width on tablets. Use semantic theme roles, 12–16dp card corners and low tonal elevation.

## Surfaces
Homepage: app bar with search/settings, upcoming class summary, seven day tabs, a time-ordered list and a single Add course FAB. Editor: toolbar, weekday chips, time buttons and labelled fields in a scrollable layout. Settings: grouped notification and backup sections with clear destructive action separation. Details: time and location prominent; edit/duplicate actions; delete with undo.

## States and verification
Empty/search-empty/loading/error states, descriptive input errors, import count preview, permission and exact-alarm status. Check emulator phone light/dark, 1.3 font scale and expanded width. Keyboard must not obscure save controls. Respect native Back and system animation settings.
